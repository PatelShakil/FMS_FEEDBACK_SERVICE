# Feedback Service

Dynamic Feedback Form Management Service for BoloIndia Platform.

## Features

- ✅ Dynamic form creation with customizable fields
- ✅ Form templates for quick deployment
- ✅ Form lifecycle management (Draft → Finalized → Active)
- ✅ JWT authentication
- ✅ MongoDB for flexible schema
- ✅ Kafka event streaming
- ✅ MinIO file storage integration
- ✅ RESTful API

## Tech Stack

- Node.js 20+
- Express.js
- MongoDB (Mongoose)
- Kafka (KafkaJS)
- MinIO
- JWT Authentication
